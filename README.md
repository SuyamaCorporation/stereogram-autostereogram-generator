# Autostereogram Random Dot 3D Generator

## 概要
深度マップを入力してランダムドットステレオグラム（Magic Eye / SIRDS形式）をcanvasで生成するジェネレーター。平行法・交差法で立体視が可能。

## 機能
- SIRDS（Single Image Random Dot Stereogram）アルゴリズム実装
- 内蔵深度マップ形状: 球体・ピラミッド・「3D」文字・星形
- カスタム描画モード: 深度マップに直接ペイント（ブラシサイズ・深度強度調整可）
- パターン幅スライダー（50〜200px）
- 最大シフト量スライダー（10〜40px、3D効果の強さ）
- ドットサイズスライダー（1〜4px）
- カラー/グレースケール切り替え
- ドット再生成ボタン（同じ深度マップで異なるランダムパターン）
- PNG保存ボタン
- 立体視の方法（平行法・交差法）の説明

## 使い方
1. 深度マップ形状を選択（球体などがわかりやすい）
2. パラメータを調整してステレオグラムを生成
3. 上のキャンバス（ステレオグラム）を画面から30〜50cm離れて見る
4. 平行法: 目の焦点を画面の後ろ（無限遠）に合わせるようにリラックス
5. 模様が重なって見えたら立体感が現れます（白=手前、黒=奥）
6. カスタム描画で自分だけの3D形状を描けます
